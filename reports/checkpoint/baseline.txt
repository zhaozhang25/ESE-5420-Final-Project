# Does an MLP beat logistic regression at predicting online purchases?

## Group
ZSC Group. Members: Wenxi, Xingyu, Zhao.

## Changes since the proposal
Following the feedback, the question is now whether a tuned MLP raises test AUPRC over tuned logistic regression by more than its error bar; we no longer assume it will. We added a stratified 20% test set, results with and without PageValues (possible leakage), five MLP seeds, and a paired bootstrap of the test AUPRC difference.

## Data

The UCI Online Shoppers Purchasing Intention dataset contains 12,330 sessions and 18 columns. The 17 predictors describe the session and visitor, and the outcome, Revenue, records whether the session ended in a purchase. We found no missing values. We removed 125 identical rows for the main analysis, leaving 12,205 sessions with a purchase rate of 15.6%.


## Split

Using seed 5420, we split the data into 9,764 development sessions and 2,441 test sessions and preserve the purchase rate in each set. Stratified five fold cross validation was used on the development set and fitted the scaler and one hot encoder within each training fold. The split and fold assignments are saved in data/splits/splits.csv so both models can use the same sessions. The test set remains unscored.


## Baseline
L2 logistic regression, with C tuned over 17 log-spaced values from 1e-4 to 1e4, scored by AUPRC. Month, VisitorType, Weekend, OperatingSystems, Browser, Region and TrafficType are one-hot encoded. CV chose C = 0.032 with PageValues and C = 0.1 without.

## Result
CV AUPRC (mean +/- SE, where SE = fold SD / sqrt(5)):
- With PageValues: 0.648 +/- 0.015 (fold SD 0.033)
- Without PageValues: 0.331 +/- 0.009 (fold SD 0.021)
- Constant score baseline: 0.156
Removing PageValues reduced AUPRC by 0.317 +/- 0.014. These estimates are approximate because the folds  are correlated, and C was chosen on the same folds, so the means are slightly optimistic. We have not evaluated the test set.


## Issues found
PageValues: 

On the decelopment set, 56.2% of sessions with positive PageValues ended in a purchase. Compared with 4.0% of sessions with zero value. We could not make sure that if the calculation includes the current session's transaction. Thus, we use the model without PageValues as the primary baseline and report the model with it as a sensitivity analysis. 

Duplicates: all 125 are non-purchase bounce sessions, so they may be separate real visits rather than errors.


Rare categories: some have one row, so the encoder ignores unseen levels.
Time: there is no date or year, and Jan and Apr are absent. Purchase rate varies from 1.6% (Feb) to 25.4% (Nov). Random folds therefore say nothing about future months.
Pipeline check: over 20 label shuffles, AUPRC is 0.159 +/- 0.001, matching random scores.
